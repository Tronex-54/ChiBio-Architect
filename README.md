# Chi.Bio Master Architect 
Chi.Bio Master Architect es una herramienta web que permite diseñar experimentos de biología sintética de forma visual, sin necesidad de escribir código manualmente. El usuario construye el protocolo arrastrando y conectando bloques — cada uno representa una acción del biorreactor — y la herramienta genera automáticamente el código Python listo para ejecutarse en el sistema Chi.Bio.
